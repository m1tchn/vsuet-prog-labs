## Алгоритмы и выбор структур данных

В `word_counts(text)` текст переводится в нижний регистр и разбивается по пробельным символам. У каждого фрагмента удаляются символы `.,!?;:` с краёв. Словарь удобен для частот, потому что ключом является слово, а значением - его количество. Метод `.get(word, 0)` возвращает уже накопленное значение или ноль для нового слова.

Функция `print_word_counts(counts)` перебирает ключи словаря через `sorted()`. У словаря и множества нет требования к порядку вывода, поэтому сортировка делает результат воспроизводимым.

В `common_topics()` используется пересечение множеств `set(first) & set(second)`, а в `all_topics()` - объединение `set(first) | set(second)`. Повторы тем исчезают, после чего результат сортируется и возвращается как список.

Для записи учебного занятия используется словарь с полями `title`, `category` и `amount`: по именам ключей понятно, что означает каждое значение, и запись легко расширить. В `totals_by_category()` словарь накапливает суммы минут для каждой категории. `titles_in_category()` возвращает названия в исходном порядке. Обе функции только читают записи и не изменяют ни список, ни вложенные словари.

В варианте 12 предметная область - музыкальные занятия, а `amount` означает минуты. Использованы пять записей и три категории; категории `фортепиано` и `вокал` повторяются:

| Название | Категория | Минуты |
| --- | --- | ---: |
| `Фортепиано: гаммы` | `фортепиано` | 45 |
| `Вокал: дыхание` | `вокал` | 30 |
| `Фортепиано: этюд` | `фортепиано` | 60 |
| `Теория музыки` | `теория` | 40 |
| `Вокал: распевка` | `вокал` | 25 |

Сводка по категориям равна `фортепиано: 105`, `вокал: 55`, `теория: 40`. В интерактивном запуске категория вводится после сводки; неизвестная категория даёт `[]`.

Кортеж применяется для неизменяемой пары значений. Например, после изменения записи:

```python
record = {"title": "Python", "hours": 2}
record["hours"] = 4
record["completed"] = False
pair = (record["title"], record["hours"])
title, hours = pair
```

Функция `updated_course_record()` возвращает эту изменённую запись и кортеж. При интерактивном запуске выводятся запись `{'title': 'Python', 'hours': 4, 'completed': False}` и распакованная пара `Пара: Python, 4`. Словарь подходит для записи, потому что поля имеют имена, а кортеж - для пары, которую не планируется изменять.

## Вывод

В работе словари использованы для соответствий и суммирования, множества - для удаления повторов и операций над темами, а кортеж - для неизменяемой пары. Перед выводом множество сортируется, чтобы порядок был стабильным. Функции не меняют входные записи, сохраняют порядок названий и корректно обрабатывают пустые и неизвестные значения.
