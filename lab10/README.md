# Лабораторная работа № 10. Текстовые файлы и обработка ошибок

## Состав работы

| Файл | Назначение |
| --- | --- |
| `files_lab.py` | Читает и проверяет прямоугольную матрицу из UTF-8-файла. |
| `table.py` | Вычисляет суммы строк и столбцов и сумму по условию варианта. |
| `main.py` | Читает `matrix.txt`, создаёт `report.txt` только после успешной проверки и обрабатывает ошибки. |
| `test_files.py` | Проверяет чтение корректных и ошибочных файлов во временной папке. |
| `matrix.txt` | Контрольная матрица в формате работы. |
| `report.txt` | Пример отчёта для контрольной матрицы. |

## Формат файла и алгоритмы

Файл `matrix.txt` хранится в UTF-8. Первая строка содержит два положительных целых числа: количество строк и количество столбцов. Далее идут ровно заданные строки с нужным количеством целых чисел. Обычный перевод строки после последней строки данных допустим; пустая строка внутри данных и лишние строки считаются ошибкой.

Функция `read_matrix(path)` открывает файл в режиме чтения через `with open(..., encoding="utf-8")`. Она отдельно проверяет пустой файл, заголовок, размеры, число строк и число значений в каждой строке. Ошибки формата превращаются в `ValueError` с номером строки, где это возможно. Ошибка отсутствующего файла сохраняется как `FileNotFoundError`, чтобы основная программа могла вывести отдельное сообщение.

`row_sums()` и `column_sums()` используют функции из работы №9. Отчёт открывается для записи только после полного успешного чтения и проверки входной матрицы. Поэтому неверный вход не стирает уже существующий `report.txt`. Входной файл никогда не открывается в режиме `w`.

В варианте 12 функция `selected_sum(matrix)` суммирует элементы строк с чётными индексами: `0`, `2`, `4` и так далее. Для контрольной матрицы:

```text
1 -2 3
4 0 -6
```

выбирается первая строка, поэтому результат равен `2`.

В `main.py` также реализована функция `read_positive_integer()`. Она различает нечисловой ввод и число, которое не больше нуля: последовательность `abc`, `0`, `-2`, `3` приводит к трём сообщениям об ошибке и возвращает `3`. Эта функция подготовлена для обязательной проверки ввода размера.

## Проверки

| Ситуация | Ожидаемый результат | Получено | Итог |
| --- | --- | --- | --- |
| `1 2` и строка `7 -1` | `[[7, -1]]` | `[[7, -1]]` | пройдено |
| `1 1` и строка `0` | `[[0]]` | `[[0]]` | пройдено |
| пустой файл | `ValueError` | `ValueError` | пройдено |
| заголовок `0 3` | `ValueError` | `ValueError` | пройдено |
| `1 2`, строка `1` | ошибка с указанием строки 2 | совпало | пройдено |
| `1 2`, строка `1 x` | ошибка с указанием строки 2 | совпало | пройдено |
| `1 1`, две строки данных | `ValueError` о лишних строках | `ValueError` | пройдено |
| отсутствующий путь | `FileNotFoundError` в функции | `FileNotFoundError` | пройдено |
| контрольная матрица | суммы строк `2 -2`, столбцов `5 -2 -3`, вариант `2` | совпало | пройдено |
| пустая выборка варианта | сумма `0` | `0` | пройдено |

Проверки запускаются командой:

```bash
python3 test_files.py
```

Основная программа запускается командой:

```bash
python3 main.py
```

Для контрольного `matrix.txt` она создаёт:

```text
Суммы строк: 2 -2
Суммы столбцов: 5 -2 -3
Результат варианта: 2
```

Сохранность старого отчёта проверена вручную: после замены входного файла на вариант с неверным заголовком `main.py` выводит ошибку формата, а существующий `report.txt` не изменяется. После проверки входной матрицы контрольный файл восстановлен.

## Вывод

В работе применены `pathlib.Path`, контекстный менеджер `with`, явная кодировка UTF-8 и обработка `FileNotFoundError`, `UnicodeError`, `ValueError` и `OSError`. Ошибка формата означает, что существующий файл прочитан, но его содержимое не соответствует правилам; ошибка доступа означает невозможность открыть или сохранить файл. Отчёт записывается только после успешной проверки, поэтому ошибочный ввод не приводит к потере предыдущего результата.
