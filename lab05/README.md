# Лабораторная работа № 5. Обработка строк

## Состав работы

| Файл | Назначение |
| --- | --- |
| `normalize.py` | Удаляет пробелы по краям, заменяет последовательности пробельных символов одним пробелом и считает слова. |
| `palindrome.py` | Проверяет строку на палиндром без учёта регистра и обычных пробелов. |
| `replace.py` | Заменяет двоеточия на дефисы и считает количество замен. |
| `variant.py` | Вариант 12: выводит слова, содержащие подстроку `ра`, после очистки краевой пунктуации. |

## Алгоритмы и прогноз результата

В `normalize.py` строка разбивается методом `split()`. Он удаляет пробельные символы по краям и отделяет слова последовательностями пробельных символов. Метод `join()` соединяет полученные слова одиночными пробелами. Исходная строка не изменяется, потому что строки в Python неизменяемы: методы возвращают новые строки.

В `palindrome.py` из текста удаляются только обычные пробелы, затем строка переводится в нижний регистр. Пустая очищенная строка обрабатывается отдельно. Для непустой строки результат сравнивается с результатом среза `[::-1]`; знаки препинания при этом сохраняются и участвуют в сравнении.

В `replace.py` сначала вызывается `count(":")`, чтобы получить число замен в исходной строке, затем `replace(":", "-")` создаёт новую строку. Поэтому исходный текст остаётся доступен до выполнения замены.

В `variant.py` текст разбивается по пробельным символам. У каждого слова символы `.,!?;:` удаляются с обоих краёв, после чего слово переводится в нижний регистр. Пустые результаты пропускаются. Для варианта 12 проверяется вхождение подстроки `ра`; подходящие слова печатаются в исходном порядке, повторы сохраняются.

Для подсчёта подходящих слов используется счётчик:

| Итерация | Очищенное слово | Условие содержит `ра` | Счётчик до | Счётчик после |
| ---: | --- | :---: | ---: | ---: |
| 1 | `анна` | нет | 0 | 0 |
| 2 | `армия` | нет | 0 | 0 |
| 3 | `край` | да | 0 | 1 |
| 4 | `рама` | да | 1 | 2 |

## Вывод

В работе использованы индексы и срезы строк, методы `strip`, `lower`, `replace`, `count`, `split`, `join`, а также проверка вхождения подстроки через `in`. Строки неизменяемы, поэтому операции обработки создают новые значения. Правила сравнения палиндрома и очистки пунктуации заданы до написания алгоритмов: это определяет, какие символы участвуют в проверке и какие слова считаются совпадениями.
