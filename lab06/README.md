# Лабораторная работа № 6. Списки и обработка наборов данных

## Состав работы

| Файл | Назначение |
| --- | --- |
| `statistics.py` | Выводит количество, сумму, минимум, максимум и среднее списка чисел. |
| `transform.py` | Создаёт новый список, заменяя отрицательные числа их модулями, и сохраняет исходный список. |
| `positions.py` | Находит все индексы максимального элемента в порядке возрастания. |
| `variant.py` | Вариант 12: отбирает положительные чётные числа и выводит их статистику и отсортированную копию. |

## Алгоритмы и прогноз результата

В каждой программе строка разбивается методом `split()`, а части преобразуются в целые числа и сохраняются в списке. Пустая строка превращается в пустой список `[]`.

В `statistics.py` для непустого списка используются `len()`, `sum()`, `min()` и `max()`. Среднее вычисляется как сумма, делённая на количество, и выводится с двумя знаками после точки. Для пустого списка эти функции не вызываются: программа выводит `Нет данных`.

В `transform.py` создаётся отдельный список `transformed`. Каждый отрицательный элемент добавляется в него с противоположным знаком, остальные элементы добавляются без изменения. Поэтому список `numbers` сохраняется и выводится отдельно от результата.

В `positions.py` сначала определяется максимальное значение. Затем `enumerate()` перебирает исходный список по парам «индекс, значение» и добавляет в новый список каждый индекс, где встретился максимум. Индексы появляются в возрастающем порядке.

В `variant.py` циклом `for` строится список положительных чётных чисел. Повторы не удаляются, поэтому каждый подходящий элемент сохраняется. После этого выводятся исходная выборка, её количество, сумма и новая копия `sorted(selected)`, отсортированная по возрастанию.

Для варианта 12 на контрольном вводе `-8 -3 0 6 6 1` накопление выборки выглядит так:

| Число | Условие `number > 0 and number % 2 == 0` | Выборка после обработки |
| ---: | :---: | --- |
| -8 | нет | `[]` |
| -3 | нет | `[]` |
| 0 | нет | `[]` |
| 6 | да | `[6]` |
| 6 | да | `[6, 6]` |
| 1 | нет | `[6, 6]` |

## Вывод

В работе использованы создание списков, `append()`, обход элементов, `enumerate()`, встроенные функции статистики и `sorted()`. Присваивание по индексу заменяет уже существующий элемент, а `append()` добавляет новый элемент в конец. Независимая копия нужна, чтобы преобразование результата не изменяло исходные данные. В варианте 12 повторы положительных чётных чисел сохранены, а сортировка выполнена над отдельным списком.
