## Задание 3. Прогноз и результат Python

До запуска были получены следующие прогнозы:

| Выражение | Прогноз | Результат Python |
| --- | ---: | ---: |
| `2 + 3 * 4` | `14` | `14` |
| `(2 + 3) * 4` | `20` | `20` |
| `17 // 5` | `3` | `3` |
| `17 % 5` | `2` | `2` |
| `-7 // 2` | `-4` | `-4` |

Все прогнозы совпали с результатами. В первом выражении умножение выполняется раньше сложения, а скобки во втором выражении меняют порядок вычислений. Оператор `//` выполняет деление с округлением вниз: `-7 / 2` равно `-3.5`, поэтому `-7 // 2` равно `-4`. Оператор `%` возвращает остаток: `17 = 3 * 5 + 2`.

Обычное деление `/` возвращает дробный результат (`float`), а `//` — целую часть результата с округлением вниз. Форматирование, например `:.2f`, задаёт только вид вывода и не меняет число, хранимое в `float`: многие десятичные дроби в двоичной системе представляются приближённо.
