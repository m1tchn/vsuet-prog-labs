# Лабораторная работа № 7. Функции и автоматические проверки

## Состав работы

| Файл | Назначение |
| --- | --- |
| `functions.py` | Содержит функции суммы цифр, среднего, нормализации текста и индивидуального отбора чисел. |
| `main.py` | Запрашивает данные и демонстрирует работу всех функций. |
| `test_functions.py` | Выполняет автоматические проверки обязательных функций и варианта. |

## Алгоритмы и прогноз результата

В `sum_digits(number)` сначала берётся модуль числа, поэтому отрицательные значения обрабатываются так же, как положительные. В цикле последняя цифра извлекается оператором `% 10`, добавляется к сумме, а число уменьшается целочисленным делением на `10`. Для нуля цикл не выполняется, и результат остаётся равным `0`.

Функция `average(numbers)` проверяет пустой список и возвращает `None`, если в нём нет элементов. Для непустого списка возвращается `sum(numbers) / len(numbers)`. Функция не меняет исходный список.

Функция `normalize_text(text)` переводит текст в нижний регистр, разбивает его по любым пробельным символам и соединяет слова одним пробелом. Исходная строка не изменяется, потому что строки в Python неизменяемы.

В индивидуальном варианте 12 функция `select_numbers(numbers, threshold)` создаёт новый список. В него добавляются только числа, для которых одновременно выполняются условия `number % 2 == 0` и `number > threshold`. Порядок и повторы сохраняются.

Для контрольного списка `[-5, 0, 2, 5]` и порога `2` подходящих значений нет: число `2` не больше порога, а `5` нечётное. Пример с совпадениями `[-4, 2, 8, 3, 8]` при пороге `2` даёт `[8, 8]`.

## Проверки

Файл `test_functions.py` запускается отдельно и не выполняет пользовательский ввод. В нём проверяются обычные, пустые и отрицательные значения, граница порога, повторы и сохранность исходного списка.

| Проверка | Ввод или вызов | Ожидаемый результат | Итог |
| --- | --- | --- | --- |
| `sum_digits` | `sum_digits(0)` | `0` | пройдено |
| `sum_digits` | `sum_digits(507)` | `12` | пройдено |
| `sum_digits` | `sum_digits(-507)` | `12` | пройдено |
| `average` | `average([])` | `None` | пройдено |
| `average` | `average([2, 4, 6])` | `4` | пройдено |
| `normalize_text` | `normalize_text("  ПРИВЕТ   Мир  ")` | `привет мир` | пройдено |
| `normalize_text` | `normalize_text("   ")` | `""` | пройдено |
| `select_numbers` | `select_numbers([-5, 0, 2, 5], 2)` | `[]` | пройдено |
| `select_numbers` | `select_numbers([-4, 2, 8, 3, 8], 2)` | `[8, 8]` | пройдено |
| `select_numbers` | `select_numbers([4, 4, 6], 2)` | `[4, 4, 6]` | пройдено |
| `select_numbers` | `select_numbers([], 2)` | `[]` | пройдено |
| `select_numbers` | исходный список после вызова | не изменён | пройдено |

Демонстрационная программа `main.py` получает четыре строки: целое число, список чисел через пробел, произвольный текст и порог. Например, ввод:

```text
-507
2 4 6
  ПРИВЕТ   Мир  
2
```

даёт сумму цифр `12`, среднее `4.0`, нормализованный текст `привет мир` и выборку `[4, 6]`.

Команды запуска:

```bash
python3 main.py
python3 test_functions.py
```

Все автоматические проверки пройдены. При намеренной замене одного ожидаемого значения в `test_functions.py` появляется `AssertionError`, после восстановления правильного значения проверки снова завершаются успешно.

## Вывод

В работе вычисления отделены от ввода и вывода: функции принимают параметры и возвращают результаты, а `main()` отвечает за взаимодействие с пользователем. Локальные переменные функций не требуют `global`. Проверки через `assert` обнаруживают ошибки автоматически. В варианте 12 новая выборка строится без изменения исходного списка, сохраняя порядок и повторяющиеся подходящие числа.
