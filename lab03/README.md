## Объяснение логики

В `point.py` используется `and`, потому что одновременно должны выполняться оба ограничения: по `x` и по `y`. В `variant.py` используется `or` для ошибки: достаточно нарушения хотя бы одной границы диапазона. В цепочке `if`/`elif` сначала проверяется ошибка диапазона, затем интервалы по возрастанию; поэтому каждое значение попадает ровно в одну категорию, включая пороговые значения. В `minimum.py` комбинация `and` с `<=` сохраняет корректность при равенстве чисел.

Для високосного года применено правило: год делится на 400 **или** делится на 4 и не делится на 100.
