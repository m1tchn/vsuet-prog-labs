# Лабораторная работа № 4. Циклы, счётчики и накопители

## Состав работы

| Файл | Назначение |
| --- | --- |
| `range_numbers.py` | Выводит все целые числа от `a` до `b` включительно в нужном направлении. |
| `statistics.py` | Для потока из `n` чисел находит сумму, количество положительных чисел и максимум без списка. |
| `positive_input.py` | Повторяет ввод, пока не получит положительное число, затем выводит его квадрат и число отказов. |
| `variant.py` | Вариант 12: одним циклом считает количество и сумму положительных чётных чисел. |

## Алгоритмы и прогноз результата

В `range_numbers.py` знак шага выбирается по отношению `a` и `b`. Правая граница `range` делается равной `b + step`, поэтому число `b` попадает в вывод при обоих направлениях. При `a == b` шаг равен `1`, и выводится единственное число.

В `statistics.py` первое число используется для начального значения максимума. Это сохраняет правильный результат, когда весь поток отрицательный. Далее `for` обрабатывает оставшиеся `n - 1` чисел и обновляет накопители.

В `positive_input.py` условие цикла проверяет введённое число. На каждой отклонённой попытке счётчик увеличивается, а новое число запрашивается снова. После положительного числа условие становится ложным, и цикл завершается.

В `variant.py` проверяется условие `number > 0 and number % 2 == 0`. Если оно выполнено, увеличиваются счётчик и сумма. При отсутствии подходящих чисел их начальные значения остаются равными нулю.

Для цикла суммирования чисел от 1 до 4 таблица значений накопителя выглядит так:

| Итерация | Число | Сумма до | Сумма после |
| ---: | ---: | ---: | ---: |
| 1 | 1 | 0 | 1 |
| 2 | 2 | 1 | 3 |
| 3 | 3 | 3 | 6 |
| 4 | 4 | 6 | 10 |

Цикл завершается, потому что `range` содержит конечное число значений. Вызов `range(a, b)` не всегда подходит для задания диапазона включительно: правая граница в нём исключается, а направление по умолчанию только возрастающее. Поэтому используется `b + step` и выбирается шаг `1` или `-1`.

## Вывод

В работе использованы циклы `for` для обработки диапазона и фиксированного количества значений и `while` для повторного ввода до выполнения условия. Счётчики хранят количество найденных или отклонённых значений, а накопители — сумму. В варианте 12 обработаны только положительные чётные числа; программа не хранит входные данные в списке.
