# Лабораторная работа № 9. Вложенные списки и таблицы

## Алгоритмы и прогноз результата

Таблица хранится как список строк: первый индекс задаёт строку, второй - столбец. Функция `row_sums(matrix)` проходит по строкам и добавляет `sum(row)` в новый список. Для пустой матрицы списковое включение сразу возвращает `[]`.

В `column_sums(matrix)` для каждого номера столбца создаётся накопитель `total`, затем вложенный цикл добавляет значение из каждой строки. Количество столбцов определяется как `len(matrix[0])`, поэтому алгоритм работает с прямоугольной матрицей, в том числе размером 2×3, а не только с квадратной. Пустая матрица отдельно возвращает `[]`.

`diagonal_pattern(size)` создаёт независимую строку для каждой строки таблицы. Для каждой ячейки сравниваются номера строки и столбца: равенство даёт `0`, строка выше столбца - `1`, строка ниже столбца - `2`. Для размера `3` получается:

```text
0 1 1
2 0 1
2 2 0
```

В варианте 12 `transform(matrix)` строит новую матрицу. Каждый нечётный элемент увеличивается на `1`, а чётный переносится без изменения. Новые строки создаются отдельно, поэтому изменение результата не затрагивает исходную таблицу.

Для контрольной матрицы `[[-2, 0, 3], [4, -5, 6]]` результат варианта 12 равен `[[-2, 0, 4], [4, -4, 6]]`.

## Вывод

В работе использованы вложенные списки и циклы для обработки строк и столбцов таблицы. Матрица 2×3 позволяет выявить ошибку, при которой алгоритм ошибочно считает таблицу квадратной. Конструкция `[[0] * columns] * rows` недопустима, потому что повторяет ссылку на одну изменяемую строку. `matrix.copy()` копирует только внешний список, а выражение `[row.copy() for row in matrix]` создаёт независимые строки. В варианте 12 преобразование возвращает новую матрицу и сохраняет исходные данные.
